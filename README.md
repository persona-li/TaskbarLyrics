# TaskbarLyrics

**[下载最新版本 → Releases](../../releases/latest)**

在 Windows 任务栏上显示歌词，不必切换到播放器，也不需要额外悬浮一个歌词窗口。

当前主要适配 **QQ 音乐**。

## 主要功能

- **任务栏歌词**：支持逐字高亮和逐行同步，自动寻找任务栏空白区域，空间不足时暂时隐藏。
- **滚动歌词**：在“正在播放”页查看随进度滚动的歌词，以及歌词源提供的翻译。
- **歌词匹配**：自动查找并缓存歌词，也可以手动搜索、选择其他版本。
- **外观调整**：自定义字体、字号、配色、阴影和位置，提供浅色、深色与跟随系统的界面主题。
- **时间校准**：分别调整当前歌曲或全部歌曲的歌词时间偏移。
- **播放控制**：支持播放／暂停、上一首／下一首；可用操作取决于播放器提供的接口。

## 开始使用

1. 打开 QQ 音乐并播放一首歌曲，再启动 TaskbarLyrics。
2. 程序会尝试自动匹配歌词，在任务栏空闲区域显示。
3. 点击系统托盘中的 TaskbarLyrics 图标打开主界面，可查看歌词、调整外观或校准时间。

关闭主界面后，任务栏歌词仍会继续运行。要完全退出，请使用托盘菜单中的“退出”。

## 常见问题

**没有匹配到歌词，或匹配到了其他版本？**

在“正在播放”页点击“选择歌词”，搜索并应用正确版本。不同语言、现场版、翻唱以及播放器提供的曲目信息，都可能影响匹配；歌词和翻译也取决于来源是否提供。

**歌词与声音不同步？**

打开“时间校准”：歌词慢了点“提前”，歌词快了点“延后”。只影响一首歌时调整当前歌曲；所有歌曲都有相同偏差时调整全局校准。

**任务栏上没有显示歌词？**

先确认主界面左下方的“任务栏歌词”开关已打开。任务栏没有足够空白区域，或处于全屏场景时，歌词可能暂时隐藏。

## 更新与卸载

| 版本 | 更新 | 卸载 |
|---|---|---|
| 安装版 | 运行新版安装包，保留原有设置 | 在 Windows“设置 → 应用 → 已安装的应用”中卸载，可选择是否同时删除个人数据 |
| 便携版 | 从托盘退出后更新程序文件，保留 `Data` 文件夹 | 如已开启开机启动，先关闭；退出程序后删除整个文件夹 |

安装版的数据保存在 `%LOCALAPPDATA%\TaskbarLyrics`。安装版与便携版不自动迁移彼此的数据。目前没有自动更新，请从 Releases 下载新版。

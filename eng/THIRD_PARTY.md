# Installer tooling

The installer is built with [Inno Setup](https://jrsoftware.org/).
`ChineseSimplified.isl` comes from the project's official translation distribution:
https://raw.githubusercontent.com/jrsoftware/issrc/refs/heads/main/Files/Languages/ChineseSimplified.isl

Its maintainer and translation credits are preserved in the file header. Downloaded
compiler binaries are build tools under `artifacts`, not application source or payload.
